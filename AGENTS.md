# Project Instructions

This is a QA Automation portfolio project for Automation Exercise.

## Tech stack
- Playwright
- TypeScript
- Page Object Model

## Test sources
- Jira is the requirement source.
- docs/test-cases/AEQA_Automation_Test_Cases.csv is the automation test case source.
- docs/manual-testing/AEQA_Manual_Test_Suite.xlsx is the manual test record.

## Rules
- Work on one test case at a time.
- Do not modify Jira unless explicitly requested.
- Read the CSV test case before implementing automation.
- Check Jira only when requirement clarification is needed.
- Use Playwright MCP when browser inspection is needed.
- Prefer stable Playwright locators.
- Do not use arbitrary hard waits.
- Do not hardcode passwords or secrets.
- Use Page Object Model.
- Explain major changes before implementing them.
